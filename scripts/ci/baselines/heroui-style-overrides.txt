# heroui-style-overrides: className/style props on a component imported from
# "@heroui/react" that set colour, background, border colour, radius (rounded-*)
# or padding at the call site instead of through the design system.
#
# Each line is `<file>:<Component>:<class token>` (or `:style.<key>`) and records
# one override that predates the rule (the v2 -> v3 migration carried them over).
# Remove a line by moving the look into a Button variant / shape, a parity
# constant in apps/web/src/lib/heroui/, or a rule on the component's BEM class in
# the gaia layer of apps/web/src/app/styles/base.css.
#
# This file only ever shrinks. A line that no longer matches anything is
# reported as removable and does not fail the gate.
