# apps/api/scripts/obscura_compat_probe.py (.github/workflows/obscura-compat.yml).
# One URL per line; a rendering gap at any other probed site fails the run.
#
# Entries are rendering gaps: the server sent both engines the same document and
# Obscura made less of it (named JS errors to patch in bootstrap.js, or a live
# site that varies between loads). A bot wall needs no entry: the probe reports
# a site that served Obscura a different document on its own, never failing.
# Seeded 2026-09-23 from two local runs: a site is here if it gapped in either
# run, from before the probe told the two apart.
#
# A line whose site now matches Chrome is reported as removable and does not
# fail the run; remove it. A site added after the seed carries its evidence in
# a comment above it.
