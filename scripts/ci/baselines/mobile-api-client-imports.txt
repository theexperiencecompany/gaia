# api-client-imports: files that import apps/mobile/src/lib/api (the raw,
# untyped request engine) from outside apps/mobile/src/lib.
#
# apiService takes any URL and any type argument, so a typo in the path or a
# guessed response shape compiles. The boundary ships as a ratchet rather than
# a Biome rule because these call sites are live: a Biome rule would have to be
# switched off to keep `biome check` green, and a switched-off rule protects
# nothing. New files fail the gate; these are the ones that already existed.
#
# This file only ever shrinks.
