# api-schema-types: hand-declared types inside an API-type directory.
#
# Every line is a declaration that predates the rule. The rule is that a type
# in apps/web/src/features/*/api, apps/web/src/types/api, apps/mobile/src/**/api
# or libs/shared/ts/src/{types,chat,bots/api} must be a re-export or an alias of
# a generated name -- those directories name the API contract and nothing else,
# so a declaration with fields of its own is a copy of a Pydantic model that
# drifts the moment the model changes.
#
# This file only ever shrinks. Adding a line is a review conversation; deleting
# one (by importing the generated type instead) needs no permission. A line that
# no longer matches anything is reported as removable and does not fail the
# gate, so emptying it never reds a concurrent PR.
