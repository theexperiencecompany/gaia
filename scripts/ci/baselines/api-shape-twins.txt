# api-schema-types: types whose FIELDS are an API model's fields under another
# name -- at least 80% of the smaller side's field names match once snake_case
# and camelCase are normalised to one spelling.
#
# A renamed twin is still a twin: the generator cannot update it, so it drifts
# silently. Each line is `<file>:<TypeName>=<SchemaName>` and records one that
# predates the rule.
#
# Some lines are heuristic rather than real -- three generic field names
# (title/description/type) can match two unrelated models. Those stay here as
# documented false positives; the ratio is deliberately not tuned around them,
# because every tightening that dropped them also dropped the real twins this
# gate was written to catch (supportApi.ts's SupportRequest/SupportResponse).
#
# This file only ever shrinks. A line that no longer matches anything is
# reported as removable and does not fail the gate.
