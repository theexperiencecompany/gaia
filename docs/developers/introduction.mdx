This tab is for people who change GAIA's code: fixing bugs, adding features, building integrations or bots, or improving these docs.

<Note>
  Want to run your own GAIA without changing its code? See [Self-Hosting](/self-hosting/overview). Using GAIA Cloud? See the [Docs](/introduction).
</Note>

## The path

Read these in order the first time. Each page links to the next.

<Steps>
  <Step title="Set up GAIA for development">
    [Install the tools, start GAIA and make your first change](/developers/development-setup). On a fresh machine most of the time goes to downloads.
  </Step>
  <Step title="Take the project tour">
    [Where each part of GAIA lives](/developers/project-tour), and where to start for the change you have in mind.
  </Step>
  <Step title="Learn the everyday loop">
    [Run GAIA locally](/developers/running-locally), [test your change](/developers/testing), [read the logs](/developers/logging) and [open a pull request](/developers/contributing).
  </Step>
</Steps>
