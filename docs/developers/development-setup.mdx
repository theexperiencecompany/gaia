## Prerequisites

<AccordionGroup>
  <Accordion icon="docker" title="Docker & Docker Compose">
    - Docker Desktop or Docker Engine
    - Docker Compose v2+
    - 10GB of free disk space
  </Accordion>

  <Accordion icon="code" title="Toolchain">
    - [mise](https://mise.jdx.dev/getting-started.html) — installs Node, Python, uv and Nx at the versions the repo pins, and runs every dev task
    - Git
  </Accordion>

  <Accordion icon="terminal" title="System Requirements">
    - macOS, Linux, or Windows with WSL2
    - At least 8GB RAM (16GB recommended)
    - SSD storage for better performance
  </Accordion>
</AccordionGroup>

## First-Time Setup

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/theexperiencecompany/gaia.git
    cd gaia
    ```
  </Step>

  <Step title="Install the toolchain">
    ```bash
    mise install
    corepack enable   # pnpm, at the version package.json pins
    ```
  </Step>

  <Step title="Set up the project">
    ```bash
    mise run setup
    ```

    Creates any missing `.env` files from their examples (`apps/api/.env`, `apps/web/.env`, `apps/mobile/.env` — existing files are never overwritten), installs JS and Python dependencies, downloads the voice models, and starts the Docker infrastructure. Team members with Infisical access can instead prefix any task with `mise infisical`.
  </Step>

  <Step title="Pick a sign-in mode and an AI key">
    You don't need a WorkOS account. Add these to `apps/api/.env`:

    ```bash
    AUTH_MODE=local          # email + password sign-in, no WorkOS
    OPENAI_API_KEY=sk-...    # or any one provider key; see Environment Variables
    ```

    With `AUTH_MODE=local`, open http://localhost:3000/signup after starting and create the first account. Leave `AUTH_MODE` unset to use WorkOS (fill the `WORKOS_*` values). Everything else is optional — see [Environment Variables](/configuration/environment-variables).
  </Step>

  <Step title="Start development">
    ```bash
    mise dev
    ```

    Runs the API and web app natively with hot reload (API on port 8000, web on 3000) and the infrastructure in Docker. `mise dev --agent` skips sign-in entirely with the dev auth bypass.
  </Step>
</Steps>

## Run Modes

| Command | Description |
| ------- | ----------- |
| `mise dev` | API + web with hot reload |
| `mise dev:vm` | API in a container (needed for JuiceFS workspace features) + web natively |
| `mise dev:arq` | API + web + ARQ background worker |
| `mise dev:full` | API + web + worker + voice agent + all bots |

See [Commands Reference](/developers/commands) for the full list.

## Troubleshooting

<AccordionGroup>
  <Accordion title="mise tasks not found or wrong tool versions">
    Make sure mise is [activated in your shell](https://mise.jdx.dev/getting-started.html), trust the repo config, and reinstall the toolchain from the repo root:

    ```bash
    mise trust
    mise install
    ```
  </Accordion>

  <Accordion title="Docker services not starting">
    Check Docker is running, then look at the infrastructure containers:

    ```bash
    docker ps
    docker compose -f infra/docker/docker-compose.yml ps
    ```
  </Accordion>

  <Accordion title="Need to reconfigure environment">
    Edit `apps/api/.env` and restart `mise dev`. To start over from the template, delete the file and run `mise run setup:env`.
  </Accordion>
</AccordionGroup>
