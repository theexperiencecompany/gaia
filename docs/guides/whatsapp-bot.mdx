## Get started

<Steps>
  <Step title="Open a chat">
    Message GAIA at [wa.me/12762088737](https://wa.me/12762088737).
  </Step>

  <Step title="Link your account">
    Send `/auth`, tap the link, and sign in.

    ```
    /auth
    ```
  </Step>

  <Step title="Just type">
    No command prefix needed.

    <Chat
      messages={[
        { from: "user", text: "Add \"renew passport\" to my todos for next week" },
        { from: "gaia", text: "Added to your todos, due next week." },
      ]}
    />
  </Step>
</Steps>

Commands work too. See the [Bot Commands Reference](/bots/commands).

## Voice notes and files

- **Voice notes** are transcribed and treated as your message. Notes over 25 MB can't be transcribed.
- **Photos and documents** are uploaded so you can ask about them.
- **Videos and stickers** aren't supported.

## Good to know

- Replies arrive as whole messages, not streamed. That's how the WhatsApp API works.
- Messages cap at 4,096 characters.
- Send `/new` when you switch topics.
- If GAIA doesn't respond, send `/status`. If your link expired, send `/auth` again.
