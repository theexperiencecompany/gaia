Open [heygaia.io](https://heygaia.io) for every GAIA feature in any browser.

## What's here

- **Chat**: talk to GAIA, upload files, see tool cards
- **Todos, calendar, and reminders**: everything GAIA tracks for you
- **Workflows**: build, run, and monitor automations
- **Integrations**: connect Gmail, Calendar, GitHub, Notion, and 60+ other apps
- **Settings**: notifications, linked accounts, usage, and subscription

Bots link back here for setup tasks like connecting integrations and building workflows.

New here? Start with the [Quick Start](/quick-start).
