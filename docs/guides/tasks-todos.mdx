You can also ask about, move, or complete tasks in bulk:

- "How many tasks do I have left in the Product Launch project?"
- "Move my marketing tasks to the Q2 Campaign project"
- "Complete all tasks labeled 'done-review'"

## How tasks are organized

| Concept      | What it does                                                      |
| ------------ | ----------------------------------------------------------------- |
| **Priority** | High, Medium, Low, or unset. Controls sort order.                 |
| **Project**  | Groups related tasks. Tasks with no project go to your **Inbox**. |
| **Label**    | A tag that cuts across projects, like "bug" or "follow-up".       |
| **Subtask**  | A step inside a task. The list shows progress, like "2/5".        |

To create a project, click **+** in the project sidebar or ask: "create a project called Product Launch".

## Long-running delegated work

For jobs that run for hours (coding agents, monitors, migrations), GAIA hands the work to a tracked task and reports back instead of making you wait:

<Chat
  messages={[
    { from: "user", text: "migrate my Postgres to Neon in OpenCode" },
    { from: "gaia", text: "On it. I'll message you when it needs you or finishes." },
  ]}
/>

Ask about progress from anywhere, even a different chat or device. GAIA reads the task's log and answers in plain words. Questions, completion, and failures arrive as messages on your preferred chat app. Everything is recorded on the task, so nothing is ever lost even if you close the app.

## Suggested workflows

GAIA can turn a task into a step-by-step plan it can run for you. Open a task and look for the **Workflow** section.

Click **Run Workflow** and GAIA carries out the steps in chat, using your connected apps.

## Find tasks

Filter the Todos page by status, priority, project, label, or date. Search matches keywords and meaning.

Select several tasks to complete, move, or delete them together.

<Warning>
  Deleted tasks cannot be recovered. Complete a task instead if you want a record.
</Warning>
