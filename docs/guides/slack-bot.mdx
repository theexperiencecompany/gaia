## Get started

<Steps>
  <Step title="Open GAIA">
    Find the GAIA app under **Apps** in your sidebar. If it's missing, click **Add apps** and search for GAIA.
  </Step>

  <Step title="Link your account">
    Run `/auth`. GAIA sends you a private link. Click it and sign in.

    ```
    /auth
    ```
  </Step>

  <Step title="Check the link">
    Run `/status`. It should show the bot and API online and your account linked.
  </Step>
</Steps>

You can also connect Slack from **Settings > Integrations** in the web app.

## Talk to GAIA

| Where | How |
| ----- | --- |
| Anywhere | `/gaia What should I focus on today?` |
| A channel | `@GAIA Summarize the last 5 emails from marketing` |
| A DM | Just type. No prefix needed. |

<Note>
  Slash command replies are private to you. @mentions and DM replies are visible to everyone in the conversation.
</Note>

For every command (`/todo`, `/workflow`, `/new`, `/stop`, `/settings`), see the [Commands Reference](/bots/commands).

## Tips

- Use DMs for personal tasks and channels for team questions.
- Run `/new` when you switch topics.
- Each teammate links their own account with `/auth` and connects their own integrations.
- Trigger shared workflows with `/workflow execute <id>`.

## Troubleshooting

| Problem | Fix |
| ------- | --- |
| No response | Run `/status`. If the bot is offline, contact your workspace admin. |
| "Account not linked" | Run `/auth`. |
| Slash command not found | Ask a Slack admin to install the GAIA app. |
| Stuck on "Thinking..." | Run `/stop`, then try again or run `/new`. |
| Integration not working | Check **Settings > Integrations** in the web app. |

Running your own bot? See the [Slack bot reference](/bots/slack).
