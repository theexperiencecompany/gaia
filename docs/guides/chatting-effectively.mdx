## Ask for things

| Type       | Example                                                                          |
| ---------- | -------------------------------------------------------------------------------- |
| Question   | "What meetings do I have today?"                                                 |
| Action     | "Draft a reply to Sarah's email"                                                 |
| Multi-step | "Find a free slot tomorrow afternoon and schedule a 30-minute meeting with Alex" |
| Research   | "Find the latest pricing for Notion's team plan"                                 |

GAIA runs multi-step requests in order.

## Be specific

Name the **who**, **what**, and **when**. GAIA then acts without asking follow-up questions.

| Vague            | Specific                                                                |
| ---------------- | ----------------------------------------------------------------------- |
| "Send a message" | "Send a Slack message to #team-eng saying the deploy is done"           |
| "Check my email" | "Find unread emails from Sarah in the last 24 hours"                    |
| "Make a task"    | "Create a high-priority task called 'Review Q2 budget' due next Monday" |

## Follow-up buttons

After each reply, GAIA suggests next steps as buttons. Click one to load it into the message box, then send or edit it.

## Pin a message

Hover over a message and click the pin icon to find it again fast.

## Turn repeats into workflows

Say "turn this into a daily workflow" and GAIA drafts one. See [Building Workflows](/guides/building-workflows).

## Good to know

- **Memory.** GAIA remembers names, preferences, and context across chats. See [Memory](/guides/memory).
- **Files.** Drag files into the chat or use the attachment button.
- **History.** The sidebar lists your past conversations.
- **Fresh start.** A new conversation keeps GAIA focused. Your memories carry over.
