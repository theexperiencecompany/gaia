Install what other GAIA users built, or publish your own workflows and MCP integrations.

## Install something

**Workflows.** On the Workflows page, use **Explore and Discover** (curated templates) or **Community Workflows** (sorted by popularity). Add any with one click.

**Integrations.** Browse the [GAIA Marketplace](https://heygaia.io/marketplace) and click **Add**. GAIA copies it to your account and connects it. Search by describing what you need, like "post messages to discord channels".

<Note>
  Community integrations connect to servers run by their creators. GAIA does not guarantee those servers stay up.
</Note>

## Publish a workflow

<Steps>
  <Step title="Create and test it">
    Give it a clear title and specific instructions. Run it at least once.
  </Step>
  <Step title="Publish">
    Open the workflow, click the three-dot menu, and select **Publish Workflow**.

    <Frame>
      <img className="rounded-lg" src="/images/guides/workflows/publish.webp" alt="Publish workflow option in the three-dot menu" />
    </Frame>
  </Step>
</Steps>

Select **View on Marketplace** in the same menu to see the public listing. To take it down, select **Unpublish Workflow**. It stays in your personal workflows.

<Tip>
  Name the apps, trigger, and output. "Daily Sales Report from HubSpot to Slack" gets more installs than "Sales Report".
</Tip>

## Publish an integration

<Steps>
  <Step title="Connect and test it">
    Add the server in **Settings > Integrations** (see [Adding MCP Integrations](/guides/adding-mcp-integrations)). Check that its tools work in chat.
  </Step>
  <Step title="Publish">
    Open the integration details and select **Publish**.
  </Step>
</Steps>

To take it down, select **Unpublish**. People who already installed it keep their copy.

Requirements:

- The server is connected and has at least one tool.
- The name is up to 100 characters. The description is optional, up to 500.
- The name and description pass an automatic profanity check.
- You are the person who added it.

<Warning>
  If your server goes down, everyone who installed it loses its tools.
</Warning>

## Community guidelines

Publish things that solve a real problem, have accurate titles, and work reliably. Mention required integrations in the description.

Do not publish anything that collects other users' data, impersonates others, spams duplicates, or asks for credentials outside GAIA. Violating content may be removed without notice.
