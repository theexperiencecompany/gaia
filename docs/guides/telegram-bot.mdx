## Get started

<Steps>
  <Step title="Open a chat">
    Search for [@heygaia_bot](https://t.me/heygaia_bot) and send `/start`.
  </Step>

  <Step title="Link your account">
    Run `/auth`, click the link, and sign in.

    ```
    /auth
    ```
  </Step>

  <Step title="Just type">
    Every message goes straight to GAIA.

    <Chat
      messages={[
        { from: "user", text: "Move my 3pm to tomorrow morning" },
        { from: "gaia", text: "Moved. Your 3pm is now tomorrow at 9:30 AM." },
      ]}
    />
  </Step>
</Steps>

Type `/` to see the command list with native autocomplete. The full list is in the [Bot Commands Reference](/bots/commands).

## Tips

- Telegram uses plain text and basic Markdown, so replies are simpler than on Discord or Slack.
- Run `/new` when you switch topics.
- Connect Gmail, Calendar, and GitHub in the [web app](/guides/connecting-integrations) first.

## Troubleshooting

| Problem | Fix |
| ------- | --- |
| No response | Run `/status`. |
| Link expired | Run `/auth` again. |
| Commands missing from autocomplete | Send `/start` to refresh. |

Running your own bot? See [Telegram Bot Development](/bots/telegram).
