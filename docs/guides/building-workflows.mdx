Describe a task once, pick when it runs, and GAIA repeats it for you.

## Fastest way: ask in chat

<Chat
  messages={[
    { from: "user", text: "Pull yesterday's key metrics from PostHog, active users, signups, and retention, and send a formatted summary to the #metrics Slack channel." },
    { from: "gaia", text: "Created. It'll run every morning and post to #metrics." },
  ]}
/>

Already asked for something you want on repeat? Say "turn this into a workflow". GAIA drafts one. Click the draft card, check it, and create it.

## Build it by hand

<Steps>
  <Step title="Open Workflows">
    Go to **Workflows** in the sidebar and click **Create Workflow**.

    <Frame>
      <img className="rounded-lg" src="/images/guides/workflows/workflows-page.png" alt="Workflows page showing existing workflows and create button" />
    </Frame>
  </Step>
  <Step title="Name it and pick a trigger">
    Use a specific title, like "Daily PostHog Metrics Report". Then choose a tab.

    | Tab          | Runs                                                              |
    | ------------ | ----------------------------------------------------------------- |
    | **Schedule** | On a daily, weekly, or monthly schedule. Defaults to 9:00 AM local time. |
    | **Trigger**  | When something happens in a connected app.                        |
    | **Manual**   | Only when you click **Run**.                                      |

    <Frame>
      <img className="rounded-lg" src="/images/guides/workflows/create-workflow-schedule.png" alt="Create workflow modal with Schedule tab selected" />
    </Frame>
  </Step>
  <Step title="Write the instructions">
    Say what to look at, what to do, and where the output goes. Then click **Create Workflow**. It is active right away.
  </Step>
</Steps>

Good prompts:

- "Check my unread emails, extract any action items, and create a todo for each one."
- "Summarize merged PRs from the past week into standup notes, grouped by project."

<Tip>
  Start with one trigger and one action. Add steps once it works.
</Tip>

## Pause a workflow

Use the activation toggle in the workflow's footer. Pausing keeps your setup.

## App triggers

Triggers are available for Google Calendar, Gmail, Google Docs, Google Sheets, GitHub, Slack, Linear, Notion, Asana, and Todoist. Connect the app first. See [Connecting Integrations](/guides/connecting-integrations).

## Start from a template

The Workflows page has **Explore & Discover** (curated templates) and **Community Workflows**. Add one with a click, then adjust it. To share yours, see [Publishing to the Marketplace](/guides/marketplace).
