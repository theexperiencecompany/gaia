Connect any [Model Context Protocol](https://modelcontextprotocol.io/) server, and GAIA picks its tools automatically when you ask.

## Connect a server

<Steps>
  <Step title="Open the form">
    On the **Integrations** page, click **New Integration** in the Custom section of the sidebar.

    <Frame>
      <img className="rounded-lg" src="/images/guides/integrations/create-custom-integration-modal.png" alt="New Integration modal with form fields for name, description, server URL, and API key" />
    </Frame>
  </Step>
  <Step title="Fill it in">
    | Field | Required | Description |
    |---|---|---|
    | **Name** | Yes | A display name, like "Notion MCP" |
    | **Description** | No | What it does |
    | **Server URL** | Yes | The MCP endpoint. Must start with `http://` or `https://` |
    | **API Key / Bearer Token** | No | Only for servers that need a static key |
  </Step>
  <Step title="Click Create">
    GAIA detects the server's authentication and connects. For OAuth servers, approve access when redirected.
  </Step>
</Steps>

GAIA imports every tool the server exposes. Those tools work in chat right away.

<Note>
  If the connection fails, the integration is still saved. Retry from the Integrations page.
</Note>

## Authentication

GAIA works out the auth type from the URL.

| Server uses      | What you do                                          |
| ---------------- | ---------------------------------------------------- |
| No auth          | Enter the URL.                                       |
| A bearer token   | Enter the token in the API Key field.                |
| OAuth 2.1        | Leave the API Key empty and approve access.          |

Find servers in the [MCP server directory](https://github.com/modelcontextprotocol/servers).
