## Get started

<Steps>
  <Step title="Add the bot">
    Use [this link](https://heygaia.io/discord-bot), join the [GAIA community server](https://discord.heygaia.io), or DM the bot.
  </Step>

  <Step title="Link your account">
    Run `/auth`, click the link, and sign in.

    ```
    /auth
    ```
  </Step>

  <Step title="Send a message">
    ```
    /gaia What's on my schedule today?
    ```

    In a DM you can skip the command and just type.
  </Step>
</Steps>

<Chat
  messages={[

    { from: "gaia", text: "You have 6 open todos, two are overdue. Want me to reschedule them?" },
  ]}
/>

For every command, see the [Bot Commands Reference](/bots/commands).

## Only on Discord

- **@mention** the bot in any channel and it replies there. No slash command needed.
- **Right-click a message** and pick **Summarize with GAIA** or **Add as Todo**. It works on anyone's message.
- **Slash command replies are private** to you by default.
- **Create a workflow** with `/workflow create <name> <description>`.

## Tips

- Connect Gmail, Calendar, and GitHub in the [web app](/guides/connecting-integrations) first.
- Use DMs for personal tasks and channels for team context.
- Run `/new` when you switch topics.

## Troubleshooting

| Problem | Fix |
| ------- | --- |
| No response | Run `/status`. Check the bot has **Send Messages** and **Use Slash Commands** in the channel. |
| Link expired | Run `/auth` again. |
| Commands missing | A server admin may need to re-deploy commands. |
| Long replies | Discord caps messages at 2,000 characters. GAIA splits them automatically. |

Running your own bot? See [Discord Bot Development](/bots/discord).
