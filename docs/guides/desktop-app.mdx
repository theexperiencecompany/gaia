Run the full GAIA web experience in its own window on macOS, Windows, or Linux.

## Install

<Steps>
  <Step title="Download">
    Get the installer for your OS at [heygaia.io/download](https://heygaia.io/download).

    | OS      | Format                                    |
    | ------- | ----------------------------------------- |
    | macOS   | `.dmg` (Intel or Apple Silicon)           |
    | Windows | `.exe` installer or portable `.exe`       |
    | Linux   | `.AppImage`, `.deb`, or `.rpm`            |
  </Step>
  <Step title="Install">
    Open the file. On macOS, drag GAIA into Applications.
  </Step>
  <Step title="Sign in">
    Click **Sign In**. Your browser opens, and the app picks up your session when you finish.
  </Step>
</Steps>

<Tip>
  On macOS, if you see "GAIA can't be opened because it is from an unidentified developer", go to **System Settings > Privacy & Security** and click **Open Anyway**.
</Tip>

## Updates

The app checks for updates on launch. When one is ready, restart now or on your next quit.

<Note>
  Updates come from GitHub Releases. If your network blocks GitHub, allow `github.com`.
</Note>

## Connect your computer to GAIA

The desktop app can let GAIA run commands on this computer. See [Device Bridge](/cli/device-bridge).

## Troubleshooting

<AccordionGroup>
  <Accordion title="Blank screen after launch">
    The app's internal server may still be starting. Wait up to 15 seconds, then quit and relaunch. Make sure nothing else uses ports 5174 to 5180.
  </Accordion>
  <Accordion title="No update prompt">
    Allow outbound HTTPS to `github.com`. Corporate proxies can block the update check.
  </Accordion>
  <Accordion title="Sign-in doesn't return to the app">
    Your OS must have the `gaia://` protocol registered. On Linux, `.deb` and `.rpm` installs do this for you. With the AppImage, launch the app once.
  </Accordion>
  <Accordion title="App won't load after an update">
    Delete the app data folder and relaunch. You will need to sign in again.

    - macOS: `~/Library/Application Support/GAIA`
    - Windows: `%APPDATA%/GAIA`
    - Linux: `~/.config/GAIA`
  </Accordion>
</AccordionGroup>
