The essentials of GAIA's visual language. Everything else is in [`DESIGN.md`](https://github.com/theexperiencecompany/gaia/blob/master/DESIGN.md) at the repo root, which is the source of truth.

## Principles

- **Dark first.** The main background is `#111111`. Light mode exists but is secondary.
- **Flat.** Depth comes from layering `zinc-800` over `zinc-900`, never from borders, rings, or outlines.
- **One accent.** `#00bbff` is the only action color. Everything else is zinc neutrals.
- **Subtle motion.** Animate entrances, exits, and state changes only. Keep durations at 300ms or less.

Use the primary color for CTAs, user chat bubbles, selection, and links. On dark card surfaces, use zinc directly instead of CSS variables.

Status badges pair a `/10` background with matching text:

```tsx
bg-emerald-400/10 text-emerald-400
```

## Shape and spacing

| Context | Class |
| ------- | ----- |
| Cards (outer and inner) | `rounded-2xl` |
| Images | `rounded-3xl` |
| Buttons, inputs | `rounded-md` |
| Badges, pills | `rounded-full` |

Outer cards use `p-4`, inner items `p-3`.

## Building UI

- Use HeroUI components, not raw HTML elements.
- Import icons from `@icons`, never raw SVGs or Unicode symbols.
- Use `cn()` to merge classes and `motion/react` for animation.
- Show toasts with `toast` from `@/lib/toast`. The toaster is already mounted.

## Do and don't

<Columns cols={2}>
  <Column>
    **Do**

    - `rounded-2xl` on card containers
    - `zinc-800` outer, `zinc-900` inner
    - `/10` backgrounds for status colors
    - `AnimatePresence` for exit animations
  </Column>

  <Column>
    **Don't**

    - `border-`, `ring-`, or `outline-` in a card tree
    - `rounded-lg` on cards
    - Solid backgrounds on status badges
    - `sonner`, `react-hot-toast`, or `framer-motion` imports
  </Column>
</Columns>
