The Telegram bot uses long polling: it asks Telegram for new messages, so it needs no webhook and no public URL.

Do the [shared bot setup](/bots/overview#shared-setup) first. You also need a Telegram account.

## 1. Create the bot

1. Open [@BotFather](https://t.me/botfather) in Telegram and send `/newbot`.
2. Choose a **name** and a **username** for your bot.
3. Copy the **bot token** BotFather gives you.

## 2. Add the token

In `apps/bots/.env`:

```bash
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
```

## 3. Start it

```bash
nx dev bot-telegram
```

On startup the bot registers its command list with Telegram, so the `/` menu shows every command without any BotFather setup. If you change the commands, restarting the bot updates the menu. `pnpm --dir apps/bots/telegram set-commands` does the same without starting the bot.

Message your bot in Telegram and send `/auth` to link it to your development user.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| The bot doesn't respond | Check that `TELEGRAM_BOT_TOKEN` is right and the process is running |
| The `/` menu is out of date | Restart the bot, or run `set-commands` as above |
| Linking fails | Check that `GAIA_BOT_API_KEY` is identical in `apps/bots/.env` and `apps/api/.env`, and that the API is running |
