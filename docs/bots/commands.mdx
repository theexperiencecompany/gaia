Every command GAIA understands on Discord, Slack, Telegram, WhatsApp, and iMessage.

## Chat and account

| Command | What it does |
| ------- | ------------ |
| `/gaia <message>` | Send a message to GAIA |
| `/auth` | Get a link to connect your account |
| `/unlink` | Disconnect your account. Re-link any time with `/auth` |
| `/status` | Check the bot and API are online and your account is linked |
| `/settings` | Show your integrations and selected model |
| `/help` | List all commands |

## Conversations

| Command | What it does |
| ------- | ------------ |
| `/new` | Start a fresh conversation. The old one stays in the web app |
| `/stop` | Stop the current response and start a new conversation |
| `/conversations [page]` | List recent conversations with web app links |

## Todos

| Command | What it does |
| ------- | ------------ |
| `/todo list` | Show active todos |
| `/todo add <title> [priority] [description]` | Create a todo. Priority is `low`, `medium`, or `high` |
| `/todo complete <id>` | Mark a todo done |
| `/todo delete <id>` | Delete a todo |

```
/todo add "Fix bug in login" high
```

## Workflows

| Command | What it does |
| ------- | ------------ |
| `/workflow list` | List your workflows and their status |
| `/workflow get <id>` | Show one workflow |
| `/workflow execute <id>` | Run a workflow now |
| `/workflow create <name> <description>` | Create a workflow (Discord only) |

## Platform differences

| Platform | Notes |
| -------- | ----- |
| Discord | Slash commands with autocomplete. Replies are private by default. You can also @mention the bot |
| Slack | Slash replies are private. DMs take free text. Channels need `/gaia` or an @mention |
| Telegram | Free text goes straight to GAIA. Supports Markdown |
| WhatsApp | Free text goes straight to GAIA. No streaming or edits. 4,096 characters per message. `*bold*` and `_italic_` formatting. Voice notes are transcribed. Video and stickers are not supported |
| iMessage | Direct messages only. Plain text |
