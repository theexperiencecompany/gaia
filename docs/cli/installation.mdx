## Install the CLI

The GAIA CLI (`@heygaia/cli`) is a terminal-based tool for setting up, configuring, and managing GAIA instances.

Install globally with your package manager:

<Snippet file="cli-install.mdx" />

## Verify Installation

```bash
gaia --version
gaia --help
```

<Tip>
  If `gaia` is not available immediately, open a new terminal session and run
  `gaia --help` again.
</Tip>

## Requirements

- **macOS, Linux, or Windows (WSL2 recommended)**
- **Node.js 20+** and one package manager (**npm**, **pnpm**, or **bun**)
- **Docker** installed and running (`gaia up` offers to install it on apt-based Linux)
- **Git** only for developer setup (`gaia init`, `gaia setup`, `gaia dev`) or `gaia up --build`. Self-hosting does not need it.

The CLI checks prerequisites during setup and guides you if something is missing.

## Upgrading

### Updating GAIA

From your install folder (`~/gaia` by default):

```bash
gaia update
```

It downloads the setup files of the release this CLI ships, pulls its images and restarts. Your `.env` files and data stay. To get a newer GAIA, update the CLI first (below), then run `gaia update` again. Contributors working from source use `gaia update --git`, which pulls the current branch and rebuilds.

## Uninstalling

To fully remove GAIA from your machine:

1. Stop all running services:

```bash
gaia stop
```

2. Delete the GAIA repository directory:

```bash
rm -rf /path/to/gaia
```

3. Remove CLI metadata:

```bash
rm -rf ~/.gaia
```

4. Uninstall the CLI:

<CodeGroup>

```bash npm
npm uninstall -g @heygaia/cli
```

```bash pnpm
pnpm remove -g @heygaia/cli
```

```bash bun
bun remove -g @heygaia/cli
```

</CodeGroup>
