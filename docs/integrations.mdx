## What's available

| Category                | Examples                                                                                          |
| ----------------------- | ------------------------------------------------------------------------------------------------- |
| Communication           | Gmail, Slack, Microsoft Teams, Google Meet                                                        |
| Productivity & tasks    | Google Calendar, Google Tasks, Google Docs & Sheets, Notion, Todoist, Asana, Trello, ClickUp, Google Maps |
| Developer tools         | GitHub, Linear                                                                                    |
| Social & business       | Twitter, LinkedIn, Reddit, Instagram, HubSpot, Airtable                                           |

The full list is in the app under **Settings > Integrations**.
