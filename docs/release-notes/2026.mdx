# Simpler Self-Hosting & a Rebuilt Browser

Self-hosting GAIA is now one command and one AI key: install the CLI with `curl -fsSL https://heygaia.io/install.sh | sh`, run `gaia up`, and open the address it prints. The [walkthrough](https://docs.heygaia.io/self-hosting/walkthrough) covers it step by step. The hosted app is now paid-only: there is no free plan, and new accounts subscribe before they reach chat. GAIA's web browsing was rebuilt to work in the background with live handoffs, and GAIA also learned to triage your Gmail every morning, follow standing instructions you give it, and react to your messages like a friend texting back.

## [API v0.25.0](https://github.com/theexperiencecompany/gaia/releases/tag/api-v0.25.0)

### Features
- **Simpler Self-Hosting**: `gaia up` does the whole setup in one step: it installs Docker if it's missing, pulls the published images and serves GAIA on one port, with automatic HTTPS when you pass a domain. Every AI feature runs on the single provider you configure (OpenAI, OpenRouter, Gemini, Ollama, or any OpenAI-compatible URL), uploads and the code sandbox need no cloud accounts, and a self-hosted instance has no paywalls.
- **Invite Your Household or Team**: On a self-hosted instance the first account is the admin, who can create single-use invite links. Each person gets their own private GAIA, and you can bring your own Composio key for integrations.
- **Paid-Only GAIA**: Hosted GAIA no longer has a free plan. Without an active subscription you can't chat on any surface, run or enable workflows, or link a bot. New users answer two questions, pick a plan and pay, choose where GAIA texts them, and land in a "Getting started" conversation.
- **A Rebuilt Browser Agent**: Browser tasks were rebuilt and work from the web app or a bot. Each step shows as a card with a photo, the run works in the background while the chat keeps going, and at a login, CAPTCHA or payment you get a live view and the run waits until you say you're done. Stop works from every surface.
- **The Inbox Desk**: Once you connect Gmail, a tracked todo triages your mail every morning: it opens a sub-todo for each thread that needs you, saves reply drafts and sends you a briefing. It replaces Inbox Triage, and feedback like "stop showing me newsletters" becomes a standing rule it follows from then on.
- **Standing Instructions**: Give GAIA instructions for every conversation or for one app, like "for Gmail, draft replies formally and never archive". GAIA can save one when you state a lasting preference, but nothing it writes is kept until you approve the exact text.
- **A Texting Voice**: Replies are short and matched to how you write, and GAIA can answer with a reaction or stay quiet when an update isn't worth a message. Charts, tables and steps render as real components again. The chat agent now runs on OpenAI's gpt-5.6-luna on every plan.
- **Several Accounts per Integration**: Connect up to five accounts per integration, such as two Gmail inboxes. One is the primary, you can say "send it from work@acme.com" to pick another, and triggers fire for every account.
- **Five New Integrations**: Cal.com, Calendly, Outlook, Jira and Dropbox.
- **Tracked Todos Report Back**: When a scheduled or triggered tracked todo finishes, its result goes to your chat app once, and only when it found something you need to know or decide. Every run is a full agent run that works from the todo's notes, and a todo can now watch a specific resource, such as one GitHub repo's pull requests.
- **Claude Code and OpenCode in Your Sandbox**: In early access, GAIA can hand long coding work to Claude Code or OpenCode in your own sandbox and gets woken when the run finishes, asks a question, needs a permission or fails. It needs a paid plan.
- **First-Steps Checklist**: Four starter steps (say hi, connect an integration, link Telegram or WhatsApp, create a workflow) that tick off from what you've actually done.
- **WhatsApp Messages After 24 Hours**: Proactive messages sent more than 24 hours after you last wrote now go out as an approved template instead of being lost.

### Improvements
- **Approvals on Chat Apps**: On Telegram, WhatsApp, Slack, Discord and iMessage, GAIA asks you to reply YES or NO instead of pointing at a card that doesn't exist there, and understands your typed reply.
- **Approval Cards Are the Confirmation**: Approving the card runs the action, so GAIA no longer asks you to confirm twice. Calendar events are created as soon as you approve.
- **More Actions Ask First**: Destructive GitHub and Slack operations now go through approval too.
- **One Limit for Recurring Schedules**: Recurring reminders, workflows and tracked todos can repeat at most once an hour, and every place that takes a schedule says so in plain words. If your subscription lapses they pause instead of hitting the paywall every tick, and resume when you subscribe.
- **Summaries Keep Your Place**: When a long conversation is compacted, the summary records what was done, with exact ids and links, and the task in progress is kept word for word.

### Bug Fixes
- **Uploads in an Existing Chat**: Files uploaded inside a chat are attached to it again, so GAIA reads the real file instead of a one-line description.
- **Send Files Without Text**: A message with only attachments now gets a reply instead of an error.
- **No Lost Turns**: Your message is saved as soon as a turn starts, and asking for the same reminder twice returns the one you already have.
- **Doubled Replies**: A model call that failed and retried no longer shows its text twice.
- **Stuck Bot Chats**: A bot conversation holding one very long reply answered every new message with an error; those chats work again, and replies no longer fill up with message-break markers.
- **"Already On It" When Nothing Was Running**: GAIA now knows whether its background work is really running, so a retry actually runs.
- **Stop Means Stop**: Stopping a task also stops the background subagents it started.
- **Missing Integrations**: An integration that no longer exists no longer replaces your answer with "I couldn't write up the result", and asking for an unconnected app gets one clear answer instead of a retry loop.
- **Inbox Desk Reads the Primary Inbox**: The desk fetched nothing and reported "nothing new"; it now reads new mail in your Primary inbox.
- **MCP Tools**: Tools whose arguments start with an underscore receive them, and an MCP tool named like one of GAIA's own is renamed instead of hidden.
- **Faster Signup**: Signing up no longer waits on the welcome email, which could stall it for over a minute.
- **Tracked Todos Close Themselves**: A tracked todo completes when its work is clearly resolved, and adding two watches at once no longer fails with "Try again".
- **Security Fixes**: Chat, upload and session routes return 404 for a conversation you don't own, and a tool no longer runs when a check before it, including the approval gate, fails.

### Performance
- **Faster First Token**: The context reads that gate a chat reply are cached, so replies start sooner.
- **Memory Recall Doesn't Hold Up Chat**: Recall gives up after five seconds instead of adding 30 to 40 seconds when the embedding service is overloaded, and its ranking step does half the work.

# Todos That Wake Themselves Up

Tracked todos can now watch for things happening outside GAIA, like a reply to an email or a calendar event about to start, and wake themselves when they do. GAIA can attach files from Google Drive to your Gmail drafts, deliver reminders back into the chat that set them, answer quick web questions on its own, and connect MCP servers you own straight from a chat.

## [API v0.23.0](https://github.com/theexperiencecompany/gaia/releases/tag/api-v0.23.0)

### Features
- **Todos That Watch for Events**: A tracked todo waiting on something outside GAIA, such as an email reply, a calendar event, a Linear issue change or a new sheet row, subscribes to it and runs the moment it happens. GAIA sets these watches on its own.
- **Google Drive and Gmail Attachments**: Connect Google Drive, and ask GAIA to "draft an email to Priya with the Q4 deck from my Drive attached". It can attach a Drive file, a file from the chat, or any downloadable URL to a real Gmail draft.
- **Reminders Come Back to Their Chat**: A reminder or tracked todo is delivered into the chat that created it, on that chat's own platform, and GAIA remembers it fired when you reply.
- **Quick Web Answers**: GAIA searches the web and reads a page itself for quick questions like weather, prices or "summarize this link", so they're answered faster.
- **Your Own MCP Servers From Chat**: Ask GAIA to add a remote MCP server by URL. After you approve, the connect card takes the server's token and connects on the spot, and MCP servers on your paired machine become available to the agent.
- **Workflows That Remember What Worked**: A workflow starts each run with a short record of the last one, and when a run's steps would work the same way tomorrow, later runs replay them in one model call.
- **Tracked Todo Notes as Files**: A tracked todo's notes are two files, canvas.md and activity.md, that GAIA edits directly.

### Bug Fixes
- **Google Calendar in Chat**: Fetching events, day summaries and finding or creating events had been returning nothing; they work again, including "what's on my calendar?".
- **Meeting Workflows**: Calendar-triggered workflows like meeting reminders and briefings failed before starting for users with tracked todos; they run again.
- **One Chat Per DM**: A bot DM is one conversation on every platform, so GAIA can see the briefing it just sent when you ask about it.
- **No Charge for Discarded Answers**: You were billed for a hidden second reply GAIA sent only to warm the model's cache. That replay is gone, and each conversation now stays on one model provider so it keeps reading from the cache.
- **Handoffs With Other App Names**: A Gmail draft that mentioned another service, like a github.com link, no longer gets rejected.
- **Cleaner Workflow Instructions**: Workflows GAIA creates for you no longer start their instructions with a copy of their schedule.
- **Your Profile Stays Intact**: A memory check could overwrite your profile with a placeholder; it now keeps the original instead.
- **Hourly Digests**: One oversized todo no longer stops everyone's dormant and expired todo digest.

# GAIA on iMessage, Approvals Before Risky Actions & Plans You Can Buy From Chat

GAIA now texts you on iMessage, asks before it does anything destructive, and can read the documents and images you send it. Plans and usage limits are live — you can upgrade to Pro without leaving the conversation — and there's a new bridge that lets GAIA work with tools and files on your own machine. The marketing site, the workflow builder's explore page, and the mobile chat experience were all rebuilt along the way.

## [API v0.22.0](https://github.com/theexperiencecompany/gaia/releases/tag/api-v0.22.0)

### Features
- **Approvals Before Destructive Actions**: GAIA now pauses and asks you first before running a tool that deletes, sends, or overwrites something, and remembers the per-tool permissions you set.
- **Device Bridge**: A secure local bridge lets GAIA reach MCP servers and files on your own machine, so it can work with what's actually on your computer.
- **Documents Read In-House**: Text-based PDFs, plus DOCX, XLSX, PPTX, and CSV files, are now extracted on our own servers rather than sent to a cloud parser, so attachments process faster. Scanned and image-based PDFs are the exception — they still go to a third-party OCR service, because reading them requires it.
- **Images and Screenshots**: GAIA reads images natively, keeps the screenshots it takes, and can download files from a URL to work with them.
- **Gmail Inbox Summary**: A dedicated tool summarizes your inbox, with cleaner email bodies so long threads read properly.
- **Plans and Usage Limits**: Free accounts now have clear daily caps and Pro runs on cost-based limits, with usage tracked per turn instead of guessed.
- **Upgrade From the Conversation**: Ask GAIA to upgrade and it hands you a real checkout link for Pro, instead of pointing you at a pricing page.
- **Ask About Your Own Billing**: GAIA can now answer "am I on Pro?", what you pay, when you renew, and what you were recently charged, from your live subscription rather than a canned pricing link — it will never cancel, refund, or discount anything on its own.
- **iMessage as a Platform**: Link your number and talk to GAIA over iMessage like any other chat platform, included with Pro.
- **A Faster Default Model**: DeepSeek V4 Flash 0731 is the new default model on every tier.
- **Lifecycle Emails**: A new email engine sends onboarding and nurture sequences, built on a provider-agnostic email service.
- **Better Workflow Creation**: Creating a workflow now runs through a structured pipeline that discovers the integrations it needs instead of guessing at them.

### Improvements
- **Model Failover That Holds Context**: Each turn resolves one model lane up front, so a provider failure now falls over cleanly without dropping your queued messages or a pending approval.
- **Replies That Sound Less Like AI**: GAIA's writing is scored against a list of AI tells — em dashes, the "it's not X, it's Y" construction — and the prompt no longer models the habits it tells the model to avoid.
- **Fresher Trigger Catalog**: Every app trigger's schema and slug is back in sync with the live Composio catalog, so event-based workflows fire on the right shape of data, and removing a trigger that's already gone no longer errors.
- **Dormant Workflows Pause Themselves**: A daily sweep pauses active workflows for accounts that have gone quiet, so nothing keeps firing in the background months after you stopped using it. They resume automatically the next time you log in.
- **New License**: GAIA is now licensed under PolyForm Noncommercial 1.0.0 instead of PolyForm Strict.

### Bug Fixes
- **Reminders Search**: Searching your reminders failed on every call; it works again.
- **Email Triggers Don't Stampede**: A busy inbox now batches into a single agent run instead of one run per message, which previously burned a day's usage in minutes.
- **Quiet Background Runs**: Scheduled workflow runs no longer email you about hitting a limit, and no longer run before you've finished onboarding.
- **Workflow Reset**: Resetting a system workflow to its default now actually uses the new prompt instead of quietly running the old one.
- **Reliable Scheduled Workflows**: Scheduled runs reschedule correctly and no longer fail on tool results that couldn't be serialized.
- **Failed Runs Are Reported as Failed**: A workflow run that errored used to be recorded as a success, which meant broken workflows kept firing forever instead of being retired.
- **No More Stray Markers in Replies**: The internal marker GAIA uses to split a long answer into separate messages sometimes reached you as literal text; every outbound path now runs through one parser.
- **The Worker Acts on What You Asked**: Longer tasks are handed to the background agent using your original wording, instead of a paraphrase that could drift from the request.
- **Unconnected Integrations**: Asking about an app you haven't connected now returns a clear message instead of an error.
- **Calendars With Special Characters**: Calendar and event IDs are URL-encoded everywhere, fixing 404s on calendars whose IDs contain special characters.
- **Sandbox Resume**: Resuming a code sandbox that had been evicted no longer 404s.
- **Memory Hygiene**: A memory is only retired when a newer one genuinely restates it, so facts about you stop disappearing.
- **No Internal Paths in Replies**: GAIA no longer leaks internal server file paths into its answers.
- **Platform Results Are Continuable**: Results delivered to a linked platform are now recorded in the conversation, so you can reply and keep going.
- **Security Fixes**: Audited SSRF, IDOR, auth, and webhook findings across the codebase were remediated, along with 192 of 196 outstanding dependency advisories.

### Performance
- **Cheaper, Faster Turns**: The prompt prefix is now stable across a conversation, so follow-up turns hit the provider's cache instead of re-paying for the whole history.
- **Leaner Tool Results**: Large tool outputs are compacted into a digest before they reach the model, keeping long tool chains fast.
- **Long Conversations Stay Light**: Saved conversation state no longer stacks a fresh copy of the system prompt on every run, which had been quietly growing the cost of every follow-up.
- **Steadier Memory Search**: Embedding and vector writes are now bounded, fixing the file-handle exhaustion that could stall memory lookups under load.

### Infrastructure
- **Safer Deploys**: Every build now gets a permanent tag, so rolling back means returning to an exact known-good version. If a build never makes it to production, we get alerted instead of never noticing.
- **A Faster CI Gate**: Checks on a pull request dropped from 13.4 to 8.9 minutes. Five of them had been quietly measuring an easier thing than they claimed to; they now measure the real one.
- **One Branch**: The `develop` branch is gone. Everything merges straight to `master`.
- **Silenced Warnings Have to Explain Themselves**: Every ignored lint or type error now records why it's there, and the cleanup removed all the stale ones nobody could account for.
- **Everything Logs the Same Way**: API, bots, and background workers now share one logging format, and the alerts were rewritten so that when one fires, it says what actually broke.
- **Tests That Run the Real Agent**: We can now drive the agent end to end and get the same result every time, so tests exercise real behaviour instead of stand-ins.
- **A Typed Database Layer**: All 33 collections go through typed code now, and model pricing moved into the codebase instead of a table that could quietly drift out of date.
- **Easier Self-Hosting**: Simpler local setup, a configurable sandbox region for EU deployments, and one identity for all secrets.

### Documentation
- **Privacy Policy and Terms**: Both rewritten from scratch to describe what GAIA actually stores, processes, and shares.

# The New Workflow Builder, Sturdier Agents & a Faster App

A redesigned workflow builder leads this release. The agent is more reliable too — it now falls back to a default model when your chosen one fails, and fails over across multiple web-search providers — while the web app gains instant navigation, a refreshed generated-UI library, and a top-to-bottom overhaul of the chat bots.

## [API v0.21.0](https://github.com/theexperiencecompany/gaia/releases/tag/api-v0.21.0)
